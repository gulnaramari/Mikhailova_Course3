# Программа для получения информации о вакансиях с платформы hh.ru в России
 
 ## Установка
 1. Клонируйте репозиторий:<br>git clone git@github.com:gulnaramari/Mikhailova_Course3.git
 2. Установите зависимости, указанные в `pyproject.toml`:<br>poetry install
 3. В рамках проекта будут получены данные о компаниях и вакансиях
 с сайта hh.ru, спроектированы таблицы в БД PostgreSQL
 и загружены полученные данные в созданные таблицы.
